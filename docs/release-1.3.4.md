# 这次更新了什么

1. **做完任务，会接着检查和收尾。** 修复以前停在“你可以手动收尾了”的情况。正常 Trellis 任务完成后，AI 会继续做全量检查，检查通过才归档、记日志。
2. **老项目也能一起更新。** 安装新版时，会更新全局技能、已经登记的项目技能和旧收尾说明。原来的任务记录、项目规范和业务代码保留。
3. **更新前先留备份。** 保留项目原有说明，重复安装不会把相同规则越加越多；安装出错会明确报错。
4. **安装和卸载更稳。** 改进大量子目录的扫描，修正目录登记、失败后误留完成标记等问题。卸载会处理两个全局技能目录，并检查目录链接，防止删错地方。

# 对你有什么用

以后正常完成 Trellis 任务，少一步手动催收尾。已经登记的旧项目升级时，也能一起使用这套流程。

单纯说“推送 GitHub”不会额外强制检查；质量检查仍然属于正常开发和收尾流程。

# 怎么升级

1. 下载下面的 `trellis-skills-1.3.4.zip` 并解压，或在原仓库中拉取最新版。
2. 在解压后的文件夹打开 PowerShell，运行：

   ```powershell
   pwsh -File install.ps1
   ```

3. 旧项目如果还没登记过，再运行一次：

   ```powershell
   pwsh -File sync-local-skills.ps1 -ProjectRoot "你的项目目录"
   ```

4. 新开 Codex 会话加载新版说明。已经打开的会话需重新读取更新后的项目说明；不用重新初始化档案柜。

需要 Windows、PowerShell 7、Python 3.10 或更高版本，以及已经安装的 Trellis 主程序。
