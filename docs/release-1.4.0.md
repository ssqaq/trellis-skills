# 这次更新了什么

1. **不用每次提醒升级了。** 开始或继续 Trellis 任务时，会顺便检查 GitHub；有新版先在后台下载，当前工作照常进行。
2. **任务做完再换新版。** 当前任务完成质量检查、归档和日志后，自动安装下载好的新版。
3. **其他项目也会跟着更新。** 已登记的空闲项目一起同步。还在工作或暂时找不到的项目会记下来，等之后具备更新条件再补齐。
4. **失败时保住现有版本。** 下载包要先校验，安装前保存原件。遇到网络或安装错误，会说明原因，不把部分更新说成全部成功。

# 对你有什么用

装好这一次之后，正常让 Codex 干活就行，不用每次再发“帮我升级 Trellis”。多个会话一起工作，也不会同时抢着安装；忙碌项目继续使用自己的原规则。

质量检查仍然跟正常开发、收尾流程走，单纯要求推送 GitHub 不会额外强制检查。

# 这次需要你做什么

1. 旧版用户先下载下面的 `trellis-skills-1.4.0.zip` 并解压。
2. 在解压后的文件夹打开 PowerShell，运行一次：

   ```powershell
   pwsh -File install.ps1
   ```

3. 新开 Codex 会话加载新版入口说明。已登记项目不用重新初始化；正在工作的项目如果显示待更新，等它自己的任务收尾后补齐。
4. 旧项目尚未登记的话，运行一次：

   ```powershell
   pwsh -File sync-local-skills.ps1 -ProjectRoot "你的项目目录"
   ```

需要 Windows、PowerShell 7、Python 3.10或更高版本，以及 Trellis 主程序。自动更新只升级本技能包的正式发布版，不升级主程序。没有任务运行时不会一直检查；网络失败继续用当前版本。

收尾时如果下载仍未完成，最多再等15秒，之后在下一次任务开始前或收尾时接着处理。查看是否更新成功，应看实际版本及待更新项目记录，不能只看下载目录。

# 已经实际测试过什么

50项自动化检查、PowerShell安装同步检查和两个真实 Codex 新任务复测通过。实际验证了“自己检查 → 继续开发 → 质量检查 → 归档和日志 → 自动安装”，以及另一个忙碌项目在自己收尾后补齐。

测试过程、发现后修复的问题和适用范围见[1.4.0验证记录](https://github.com/ssqaq/trellis-skills/blob/v1.4.0/docs/verification-1.4.0.md)。本次正式版本为1.4.0；测试中的模拟版本没有发布到 GitHub。
